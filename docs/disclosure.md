# 🔒 Disclosure & Privacy

I compete under each event's rules of conduct — including the **NCL Code of Conduct /
Ethical Behavior policy**, which governs sharing and unauthorized assistance. To honor
that — and to avoid spoiling challenges that may be reused — every write-up here follows
these rules:

1. **Technique over artifact.** I describe the vulnerability/problem *class*, my reasoning,
   and the tools — never flags, answers, challenge prompts, provided files, or credentials.
2. **Nothing copied verbatim.** No encoded strings, hashes, file names, or recovered secrets
   from any challenge appear in this repository.
3. **No teammate content.** Team-game specifics and anything attributable to teammates are
   excluded; only my own tooling and generalized methodology are shown.
4. **Reconstruct, don't reproduce.** Where an example helps, I use a small, self-authored
   demo illustrating the concept.

!!! note
    No proprietary competition content is reproduced here. If you believe anything
    oversteps, please open an issue and I'll address it promptly.
